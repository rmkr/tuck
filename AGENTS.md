# Tuck

Tuck is a Rust memory service for coding tools on one computer. Before implementation, read `docs/implementation-plan.md` and its linked specification and tickets. Use `docs/research.md` for the research background.

Use Zed as the default editor. Validate agent connections directly over MCP. An editor is optional for validation.

## Agent skills

Use the installed [Matt Pocock engineering skills](https://github.com/mattpocock/skills) when they apply. Follow each skill's invocation rules.

### Issue tracker

Specs and tickets live in GitHub Issues for `rmkr/tuck`. Before reading or publishing them, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

This repo uses one domain glossary. Before exploring the codebase, read `docs/agents/domain.md`.
