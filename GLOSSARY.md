# Tuck

Tuck lets coding tools share selected memories for one user. A memory keeps a claim with the context needed to judge and revise it.

## Language

### Memory

A saved preference, decision, fact, or lesson with a source and a scope.

### Scope

The project or explicitly shared user context to which a memory belongs.

### Source

The reference and declared origin that attribute a memory's claim.

### Revision

The numbered state of a memory after a successful save or correction.

### Client grant

The scopes and read/write rights assigned to one authenticated coding-tool connection.

### Operation receipt

The content-free record of a mutation's outcome that makes repeated requests safe.
