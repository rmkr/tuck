# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must assess the issue. |
| `needs-info` | `needs-info` | The issue needs more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The maintainer has declined the issue. |

When a skill names a triage role, use its label from this table.
